# Game Compatibility List
| Game | Android Version | Architecture | Status | Notes | Tested on |
|---|---|---|---|---|---
| BitBlocks | Android 1.1 | Universal | Perfect | ~24-30fps | Wii U (hardware) |
| Little Python | Android 1.6 | Universal | Perfect | Works perfectly like original game | Wii U (hardware) |
| Little Python | Android 1.6 | Universal | Perfect | Works perfectly | Linux x86_64 (dev) |
| PAC-MAN by Namco | Android 1.0? | Universal | Menu | Crashes when attempting to get in-game. | Wii U (hardware) |
| Replica Island | Android 1.5 | Universal | Crashes | No OpenGL implementation yet | Wii U (hardware) |

## Key

| Status | Description |
|---|---|
| Perfect | Fully working with no issues |
| Playable | Playable with minor issues |
| In-Game | Reaches gameplay with significant issues |
| Menu | Menus work, gameplay does not |
| Crashes | Crashes on boot or does not work |
